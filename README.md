 Jogo de Dados em Java

Este é um simples **Jogo de Dados** feito em Java, onde o usuário pode lançar um dado, ver os resultados dos lançamentos, incluindo a soma total e a média dos valores lançados.

## Funcionalidades

- O jogador pode lançar um dado várias vezes.
- A cada lançamento, o número gerado é somado e exibido.
- Ao final, o programa exibe:
  - O total de lançamentos.
  - A soma total dos números lançados.
  - A média dos lançamentos.
